# تعليمات رفع الملفات

لرفع الملفات على GitHub، قم بتنفيذ أحد الخيارات التالية:

## الخيار 1: استخدام ملف Batch
انقر نقراً مزدوجاً على `deploy.bat`

## الخيار 2: استخدام PowerShell
افتح PowerShell في هذا المجلد وقم بتنفيذ:
```powershell
.\deploy.ps1
```

## الخيار 3: الأوامر اليدوية
```bash
git add .
git commit -m "Upload langquiz project files"
git push -u origin main
```
